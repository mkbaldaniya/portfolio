## 🖥️ Local Setup & Deployment Guide

Follow these steps to run the portfolio website locally on your computer or host it on your preferred platform:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/mkbaldaniya/saveweb2zip-com-slimhamdi-net.git
cd saveweb2zip-com-slimhamdi-net
```

### 2️⃣ Run Locally
Since this is a static single-page web app, you can simply:
- **Option A (Direct File opening):** Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Safari).
- **Option B (VS Code Live Server):** Right-click `index.html` in VS Code and click **"Open with Live Server"**.
- **Option C (Python HTTP Server):**
  ```bash
  python -m http.server 8000
  ```
  Then visit `http://localhost:8000` in your browser.
